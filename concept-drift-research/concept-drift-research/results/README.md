# results/

Everything here is generated by executing the notebook or `scripts/run_experiments.py`.

* `raw/<tag>_runs.csv` — one row per (scenario, seed, policy) run with all metrics, timing and run parameters.
* `raw/<tag>_drift_events.csv` — one row per (run, drift event).
* `raw/<tag>_monitor_runs.csv` — monitor-only detector evaluations (6 detector settings per scenario/seed).
* `raw/<tag>_memory.csv` — tracemalloc peak memory (separate pass).
* `logs/<tag>_event_log.csv` — time-indexed alarms and adaptation events of every run.
* `logs/<tag>_prequential_errors.npz` — per-observation error indicators of every policy run (uint8).
* `logs/<tag>_config.json`, `logs/environment.txt`, `logs/<tag>_failed_runs.csv`, `logs/realworld_status.txt`.
* `tables/*.csv` — all exported result tables (see notebook Section 16).

`<tag>` is `main` for the full profile and `smoke` for the quick pipeline check (never report smoke numbers).
